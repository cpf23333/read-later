稍后再看 - 隐私政策

最后更新日期：2026-08-11

「稍后再看」（ReadLater）是一款浏览器扩展，用于帮助用户收藏和管理网页链接。我们非常重视您的隐私。

1. 数据收集

本扩展不会收集任何个人信息，也不会将您的数据发送到第三方服务器。

扩展仅在您主动操作时收集以下信息：

  • 您选择保存的链接 URL
  • 链接对应的页面标题
  • 您当前访问页面的截图（仅在您主动保存时生成）
  • 链接附近的图片（仅在您主动保存时提取）

2. 数据存储

所有数据默认存储在您自建的服务器上（通过扩展设置页面配置服务器地址和 API Key）。

扩展作者或服务提供商无法访问您的数据，除非您主动将服务器暴露到公网。

3. 权限说明

扩展需要以下权限才能正常工作：

  • contextMenus：在右键菜单中添加"收好链接"选项
  • activeTab / tabs：获取当前页面标题和截图
  • storage：保存扩展设置（如服务器地址、API Key）
  • alarms：用于未来的定时任务
  • host_permissions：获取页面标题需要访问当前页面

4. 第三方服务

本扩展不依赖任何第三方分析、广告或追踪服务。

5. 数据安全

建议您：

  • 为自建服务器设置强密码（API Key）
  • 仅在受信任的网络环境中暴露服务器
  • 定期备份数据目录

6. 联系我们

如果您对隐私政策有任何疑问，请通过项目仓库提交 Issue。
