# Chrome Web Store 发布文案

## 扩展名称

稍后再看 - ReadLater

## 一句话摘要（最多 132 字符）

右键或长按保存链接，自动记录页面标题、截图和附近图片，支持多设备同步。

## 详细说明

「稍后再看」是一款轻量级的链接收藏管理工具，帮助你在浏览网页时快速保存感兴趣的链接，稍后有空再阅读。

**主要功能：**
- 🖱️ 右键菜单：在任意链接上右键，选择"收好链接"
- 📱 移动端支持：在安卓浏览器上长按链接即可保存
- 📸 自动截图：保存时自动截取当前页面
- 🖼️ 图片提取：自动抓取链接附近的图片作为封面
- 🔍 快速搜索：支持多关键字搜索、域名筛选、日期筛选
- 🗑️ 回收站：删除的链接可在回收站还原或永久删除
- ☁️ 多设备同步：通过自建服务器实现数据同步
- 🌙 深色模式：保护眼睛
- ⌨️ 键盘快捷键：提升操作效率

**隐私优先：**
所有数据存储在你自建的服务器上，扩展不会收集任何个人信息，也不会将数据发送到第三方服务。

**适用场景：**
- 看到好文章来不及读，先收起来
- 收藏教程、资料、工具网站
- 整理研究素材和参考资料
